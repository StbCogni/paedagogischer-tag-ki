DER KONTEXT — WAS DAS MODELL „SIEHT"

DieKatzesitztaufder___

Das Modell liest alle bisherigen Wörter.

Genau wie Google Autofill — aber statt nur das letzte Wort zu sehen, versteht ein LLM den gesamten Kontext auf einmal.

DIE WAHRSCHEINLICHKEITEN — KEINE GEWISSHEIT

DieKatzesitztaufder?
Matte
42 %
Fensterbank
28 %
Couch
18 %

8 %

4 %

Das Modell wählt nicht immer die wahrscheinlichste Option — sonst wäre jeder Text gleich. Eine Prise Zufall macht die Antwort natürlicher.

DER PROZESS WIEDERHOLT SICH — WORT FÜR WORT

DieKatzesitztaufderMatte___

Jetzt beginnt alles von vorn: Das Modell liest „Die Katze sitzt auf der Matte" und sagt das nächste Wort vorher.

So entsteht ein ganzer Text — ein Wort nach dem anderen, tausende Male pro Sekunde.

💡 DAS GEHEIMNIS

Das Modell versteht nichts.

Es hat auf riesigen Mengen Text gelernt, welche Wörter häufig aufeinanderfolgen. Es hat kein Bewusstsein, keine Meinung, keine Absicht.

Deshalb kann es überzeugend klingen — und trotzdem falsch liegen.

→ Genau das ist der Grund, warum Reflexion und Quellenprüfung so wichtig sind.
